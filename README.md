# UAV Autonomous Optimization

Repository for the **Hack the Drone - MATLAB Hackathon** project:

Optimize a drone’s ability to autonomously follow a path in a simulated 3D environment using **MATLAB, Simulink and Stateflow**.

## Challenge Context

This project targets the MathWorks + MATLAB Student Ambassadors hackathon focused on autonomous drone path planning in simulation.

Main objective:
- Build robust decision-making logic to let a drone follow a detected track in a simulated 3D environment.

## Required Software and Toolboxes

Install:
- MATLAB
- Simulink
- Simulink Support Package for Parrot Minidrone

Required toolboxes/products:
- Aerospace Toolbox
- Computer Vision Toolbox
- Control System Toolbox
- Signal Processing Toolbox
- Embedded Coder
- Simulink 3D Animation
- Stateflow

## What to Build

Use the provided simulation/control architecture to:
1. Process camera feed blocks to detect the track.
2. Implement path-planning and decision logic in Simulink/Stateflow.
3. Tune behavior for stable autonomous path following.

## How to Run

1. Open MATLAB.
2. Clone this repository and set it as current folder.
3. Open the project model (`.slx`) for the drone simulation/control workflow.
4. Run the simulation from Simulink.
5. Adjust Stateflow/logic blocks and controller parameters, then rerun to optimize tracking performance.

> Note: Ensure all required toolboxes and the Parrot Minidrone support package are installed before running.
